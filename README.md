# RMRRT project page

The project page of **RMRRT: Riemannian Barrier Metric RRT for Inequality-Aware Steering on Equality
Manifolds** (IEEE Transactions on Robotics, 2026), served at https://rcilab.khu.ac.kr/rmrrt/.

Code: https://github.com/rcilab/rci_rmrrt

Preview locally (the interactive demo loads its data with `fetch`, which browsers block on `file://`):

```sh
python3 -m http.server 8000    # then open http://localhost:8000
```
